AI AGENT GOVERNANCE POLICY v2.0
Classification: Internal Policy Document
Owner: Chief Compliance Officer
Effective: January 1, 2026
Review cycle: Quarterly

===== 1. PURPOSE AND SCOPE =====

This policy establishes requirements for the development, deployment, and
monitoring of AI agents within the organization. It applies to all autonomous
AI systems capable of taking actions, reading data, or producing outputs that
affect business processes, customer data, or third-party systems.

This policy is enforced by the norma.ai governance platform. All production AI
agents must be registered with norma.ai before deployment.

===== 2. AGENT CLASSIFICATION =====

2.1 Tier Definitions

RESTRICTED: New agents or agents with recent violations. Default state.
  - Limited data access (public/read-only only)
  - Runs logged and reviewed weekly
  - No autonomous write operations permitted
  - Maximum 10 runs per day without compliance officer review

STANDARD: Agents with 10+ clean runs and trust score ≥ 0.65.
  - Standard data access per approved contract
  - Runs logged, reviewed monthly
  - Write operations permitted within contract scope
  - Anomaly alerts active after 20-run baseline established

TRUSTED: Agents with 20+ clean runs and trust score ≥ 0.82.
  - Expanded data access as approved
  - Runs audited quarterly
  - Delegation to sub-agents permitted (max 3 simultaneous)
  - SLA thresholds enforced automatically

2.2 Tier Changes
  - Promotion: Requires norma.ai contract approval by authorized reviewer
  - Demotion: Automatic and immediate on any policy violation
  - Re-promotion after demotion: Requires fresh 10 clean runs from restricted

===== 3. CONTRACT REQUIREMENTS =====

3.1 Every production AI agent must have an approved governance contract that specifies:
  - Permitted tools and data access paths
  - Prohibited tools and data access paths
  - Output constraints (PII, credentials, sensitive patterns)
  - SLA bounds: cost per run, latency, minimum quality score

3.2 Contracts must be:
  - Generated by the norma.ai platform from introspected agent code
  - Reviewed by a qualified reviewer before activation
  - Approved via the norma.ai UI (no manual YAML editing in production)

3.3 Contract versions:
  - Each code change triggers a new contract proposal
  - Active contract remains in force until new version is approved
  - All contract versions retained for 7 years (audit requirement)

===== 4. DATA ACCESS RULES =====

4.1 Permitted by default (all tiers):
  data/public/** — earnings reports and public documents
  data/research/** — industry research documents

4.2 Standard and Trusted tiers only:
  data/compliance/** — vendor risk and audit documents (read-only)
  data/support/** — customer support KB (read-only)

4.3 Never permitted (any tier, requires CISO approval):
  data/confidential/** — executive compensation, internal strategy
  data/support/payments/** — payment transaction records
  crm/** — customer PII databases
  infrastructure/secrets/** — credentials and API keys

4.4 AI agents are prohibited from writing to any data store unless explicitly
    approved in the contract and logged via norma.ai telemetry.

===== 5. MONITORING REQUIREMENTS =====

5.1 All AI agent runs must be logged with:
  - Tool calls made (name, input, output, latency)
  - Data paths accessed
  - Policy enforcement outcomes
  - Quality score and trust impact

5.2 Violations require automatic trust score penalty (0.25 reduction).
    Three violations within 30 days → mandatory human review before resumption.

5.3 Security incidents involving AI agents (unauthorized data access, output
    containing PII/credentials) must be reported to the CISO within 24 hours.

===== 6. EXCEPTION PROCESS =====

Exceptions to this policy require:
  1. Written justification from the requesting team's VP
  2. Security risk assessment by InfoSec
  3. CISO approval and documentation in the exception register
  4. Time-bound waiver with defined expiry date
